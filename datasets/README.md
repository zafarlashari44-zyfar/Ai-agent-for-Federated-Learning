# ECG Dataset

The processed ECG NumPy files are not stored in GitHub because they are large.

Place them inside:

datasets/records

Expected file naming:

data_mitdb_100_beats.npy
data_mitdb_100_labels.npy

Each ECG beat file should contain 216 input values per beat.

The labels should use the AAMI classes:

N
S
V
F
Q
